DURUM OZETI
-----------
Fastify 5 + node:sqlite (Node 24, derleme gerektirmez; better-sqlite3 GEREKMEDI). Sozlesmedeki
TUM uclar yazildi ve curl/node ile denendi (auth, admin kullanici, katalog arama+cache+kapak,
talepler+bildirim, entries+progress+stats, yorum, soru-cevap, feed, 3 liderlik, yedek).
Bilinen eksik/risk en altta. Test ajani: kendi DB'nizle 4100'de calistirin (start-backend.js
`node src/server.js` diyor; calisir. Uyari mesajini susturmak icin `npm start` de kullanilabilir).

CALISTIRMA
----------
  cd backend && npm install && npm run seed && npm run dev      (http://localhost:4000)
  - npm run seed : katalogu internetten doldurur (kitap/dizi/film, Turkce populerler dahil).
    ~10-15 dk surer (nazik bekleme), tekrar calistirmak guvenli, tek tur: `npm run seed -- book|series|movie`.
    Seed'siz de uygulama calisir; katalog arama sirasinda zaten internetten dolar.
  - npm start : izleme (watch) olmadan.
Ortam degiskenleri:
  PORT (4000) | DB_PATH (backend/data/kutuphane.db) | COVERS_DIR (DB'nin yanindaki covers/)
  ADMIN_PASSWORD (yoksa "degistir-beni" + konsola uyari + user.must_change_pw=true)
  TZ_NAME (Europe/Istanbul; "bugun" hesabi) | TRUST_PROXY=1 (ters vekil arkasinda) |
  FETCH_TIMEOUT_MS (6000; dis kaynak zaman asimi)
Ilk calistirmada admin olusur: kullanici adi "admin". Signup yok.

AILEYE KURULUM
--------------
 1) Bilgisayara Node 24+ kur. Proje klasorunde:   cd backend && npm run kur
    (ilk seferde ~1-2 dk: bagimliliklar + arayuz derlemesi). Sonraki acilislar: `npm start`.
 2) Sunucu 0.0.0.0:4000'de dinler ve acilista "Aile aginda: http://192.168.x.y:4000" satirlarini yazar.
    Aile uyeleri AYNI Wi-Fi'da telefondan o adresi acar (ornegin http://192.168.1.20:4000). Telefon icin ek ayar yok.
 3) Windows Guvenlik Duvari ilk acilista soru sorar: "Ozel aglar"a izin ver (yoksa telefon baglanamaz).
    Bilgisayarin IP'si degisirse yeni adresi kullan; router'da bilgisayara sabit IP verilmesi onerilir.
 4) Ilk giris: ADMIN_PASSWORD verilmediyse konsolda rastgele admin sifresi yazar (bir kez); girince degistirmeniz istenir.
    Onerilen: PowerShell'de `$env:ADMIN_PASSWORD="guclu-bir-sifre"; npm start`. Sonra Yonetim'den aile uyelerini ekleyin.
 5) Cookie: http (https degil) ile calisir. Internete https ile acarsaniz (ters vekil/Cloudflare tunnel) COOKIE_SECURE=1
    ve TRUST_PROXY=1 ayarlayin. Dogrudan internete 4000 portunu ACMAYIN (https yok).
 6) Veri: backend/data/kutuphane.db (+ covers/). Yedek: Yonetim'de "Yedek indir" (GET /api/admin/backup) ya da dosyayi kopyalayin.
 7) Katalogu doldurmak istege bagli: `npm run seed` (kitap/dizi; film Wikidata hiz siniri nedeniyle `npm run seed -- movie` ayri).
 8) Gelistirme: `npm run dev` (4000) + frontend `npm run dev` (5173, /api proxy). Baska portta backend icin CORS_ORIGIN.
